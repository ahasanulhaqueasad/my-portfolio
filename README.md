# ASAD. — Web Developer Portfolio

A modern, responsive, and animated personal portfolio website built to showcase my skills, projects, and services as a Web Developer.

## 🌐 Live Demo

[**View My Portfolio**](https://ahasanulhaque.vercel.app/)

## 📸 About the Project

This portfolio website presents my professional profile, technical skills, featured projects, and web development services. It also includes a contact form that helps visitors prepare an email to reach me.

The website is designed with a modern dark theme, smooth animations, and a responsive layout for desktop, tablet, and mobile devices.

## ✨ Features

- Modern and responsive UI
- Personal introduction and About page
- Featured projects with technology tags
- GitHub and Live Demo links for projects
- Web development services section
- Contact form with email preparation
- Smooth animations and hover effects
- Responsive navigation menu
- Reusable React components
- Client-side routing

## 🛠️ Technologies Used

- **React** — UI development
- **Vite** — Development server and build tool
- **JavaScript** — Application logic
- **Tailwind CSS** — Styling
- **DaisyUI** — UI component styling
- **React Router DOM** — Client-side routing
- **Motion** — Animations
- **React Icons** — Icons
